# Eval Fixtures

Public repository fixtures must be synthetic or de-identified unless a specific real source is explicitly authorized for publication.

Planned frozen benchmark layers:

- 12–15 real/de-identified Opportunity cases for internal/private evaluation
- 3 frozen Search pools
- 5 portable synthetic/de-identified candidate profiles with 2–3 jobs each
- Positioning/Application checks derived from Pursue cases
- Learn sequences, repeat-stability and monotonicity cases

The public repo should contain portable/synthetic fixtures only. Private real-user benchmark material remains outside the public package.
