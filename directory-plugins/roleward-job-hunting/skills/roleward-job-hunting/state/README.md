# Local Alpha State / 本地 Alpha 状态

Runtime user state lives in this directory but is ignored by Git.

Default file used by the helper scripts:

`state/roleward-state.json`

The tracked schema is `schemas/roleward-state-v0.schema.json`.

Do not commit real CVs, AI-context exports, job-search history, application artifacts, or user state.
